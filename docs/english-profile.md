# 英语薄弱自学者画像

## 目标用户

- CET-4/考研英语/自考英语等，阅读慢；
- 习惯逐词查词典，查完仍不懂整句；
- 认识一些词，但不知道这句用哪个义项；
- 阅读时被生词打断，读完记不住；
- 不想先学一整套语法，只想把当前这段读懂。

## 设计原则

### 1. 语境先于词典

先回答“这个词在这句里做什么”，再给中文意思。不把词典十条义项倒出来。

### 2. 句子先于单词

先给主干提示，再挂修饰/从句。用户需要知道“谁做什么”，而不是一堆词的中文。

### 3. 每句最多三个候选词

英语薄弱者一次处理不了十个生词。默认三个，用户可以在画像里改。

### 4. 一句一义

一张语境卡只装一个义项、一个依据、一个例句。不要把多个义项塞进一张卡。

### 5. 来源可回查

卡片保留原句和 source id；没有原文页码就标“页码未给”，不猜。

### 6. 证据分档

- 看过卡 = 曝光；
- 在原句认出 = 识别；
- 换句说对 = 回忆；
- 自己用出来 = 产出。

只有后两档才算“会用”，不把“看过”当掌握。

## 一次阅读的理想流程（v0.3 目标）

1. 贴一段文章；
2. 自动切句，每句最多标 3 个候选词；
3. 点一个词，弹出语境卡：这句里的意思、依据、搭配、一个同义项新例句；
4. 句子下方给“主干/修饰”折叠提示，不默认展开语法课；
5. 读完后只留 3–5 张卡进复习，不把整篇都变成卡片；
6. 第二天用填空卡复习，答错回到原句，不重讲整篇。

## 不做什么

- 不做完整词典；
- 不自动评分作文；
- 不押题；
- 不承诺“几天背完多少词”；
- 不用“看懂了”代替“能回忆/能产出”。
